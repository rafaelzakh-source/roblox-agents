# Конвейер команды Roblox-агентов

Главная сессия - «руководитель»: сама крупно не пишет код, а раздаёт задачи агентам плагина roblox-team и сводит результат. Агенты не могут вызывать друг друга - передачу работы между ними делает главная сессия.

## Правило №1 - всегда начинать и заканчивать с хранилища
- **В начале каждой задачи** вызови **roblox-lorekeeper** (режим «перед задачей»). Его «Контекст», «Числа и правила» и «План раздачи» передавай дальше другим агентам в их задания.
- **В конце задачи** снова вызови **roblox-lorekeeper** (режим «после задачи») с кратким итогом: что сделано, какие решения приняты.
- Если хранилище не найдено - попроси автора указать путь в CLAUDE.md (`Obsidian-хранилище: <путь>`), а пока работай без него.

## Конвейер для новой фичи
1. **roblox-lorekeeper** - что уже известно о фиче из заметок.
2. **roblox-analyst** - как сейчас устроен затронутый код.
3. **roblox-designer** - если фича новая или неясная: дизайн-док в `docs/design/` и план задач. Показать автору и дождаться «ок». Числа - через **roblox-economy-balancer**, удержание и монетизация - через **roblox-engagement-designer**.
4. Исполнители по плану, по одной задаче:
   - код - **roblox-builder**;
   - экраны и кнопки - **roblox-ui-designer**;
   - карта и уровни - **roblox-level-builder**;
   - модели/звуки/текстуры - **roblox-asset-finder**, затем вставка - **roblox-studio-operator** или **roblox-model-fixer**;
   - эффекты, звуки, анимации - **roblox-vfx-sound**.
5. **roblox-reviewer** - проверяет каждое изменение кода.
6. **roblox-tester** - тесты и чек-лист в `docs/qa/` (с Play-тестом через **roblox-studio-operator**, если подключён MCP Studio).
7. **roblox-polisher** - исправляет замечания 5–6 и доводит качество.
8. Были КРИТИЧНО-замечания - снова шаг 5.
9. **roblox-lorekeeper** - записать итоги в хранилище.

## Короткие маршруты
- «Посмотри / объясни» → lorekeeper → analyst (или studio-operator, если речь про то, что в Studio).
- «Придумай» → lorekeeper → designer (→ economy-balancer для чисел).
- «Ошибка / не работает / баг» → lorekeeper → **roblox-debugger** → reviewer → lorekeeper.
- «Модель не вставляется / разваливается / не та» → **roblox-model-fixer** (+ studio-operator) → lorekeeper.
- «Найди модель / звук» → **roblox-asset-finder** → model-fixer (проверка и вставка).
- «Сделай интерфейс» → lorekeeper → **roblox-ui-designer** → reviewer.
- «Построй карту / уровень» → lorekeeper → **roblox-level-builder** → tester.
- «Баланс / цены / слишком легко» → lorekeeper → **roblox-economy-balancer**.
- «Игроки уходят / мало возвращаются / мало покупают» → lorekeeper → **roblox-engagement-designer** → designer/economy-balancer → исполнители.
- «Сделай красивее / сочнее» → **roblox-vfx-sound** и/или **roblox-polisher** → reviewer.
- «Публикуем / обновление» → **roblox-publisher** (+ скилл `publish-check`) → исправления по блокерам → publisher ещё раз.

## Правила для всех
- Сервер главный, клиенту не доверяем.
- Если подключён MCP-сервер Roblox Studio - проверять результат в живой игре, а не только в коде.
- Перед большими изменениями - коммит, чтобы можно было откатить.
- Отчитываться автору простым языком по-русски: что сделано, как проверить в Studio, что осталось.
