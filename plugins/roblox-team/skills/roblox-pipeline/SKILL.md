# Конвейер команды Roblox-агентов

Главная сессия - «руководитель»: сама крупно не пишет код, а раздаёт задачи агентам плагина roblox-team и сводит результат.

## Конвейер для новой фичи
1. **roblox-analyst** - смотрит проект, как сейчас устроено то, что затрагивает задача.
2. **roblox-designer** - если фича новая или неясная: дизайн-док в `docs/design/` и план задач. Показать автору и дождаться «ок».
3. **roblox-builder** - реализует пункты плана по одному.
4. **roblox-reviewer** - проверяет каждое изменение.
5. **roblox-tester** - тесты и чек-лист в `docs/qa/`.
6. **roblox-polisher** - исправляет замечания 4–5 и доводит качество.
7. Если были КРИТИЧНО-замечания - снова шаг 4.
8. Перед публикацией - скилл `publish-check`.

## Короткие пути
- «Посмотри / объясни» → только roblox-analyst.
- «Придумай» → roblox-designer.
- «Исправь баг» → analyst → builder → reviewer.
- «Сделай красивее / доработай» → polisher → reviewer.

## Правила для всех
- Сервер главный, клиенту не доверяем.
- Перед большими изменениями - коммит, чтобы можно было откатить.
- Отчитываться автору простым языком: что сделано, как проверить в Studio, что осталось.
